# Field Edge Harvesting

[Field Edge Harvesting mod icon](FEH-icon.png)

**A realism-focused mod for Farming Simulator 25**

Field Edge Harvesting is a Farming Simulator 25 mod that aims to make harvesting more realistic by allowing combine harvesters to cut grass growing along the edges of cultivated fields.

In real-world farming, grass and weeds can sometimes grow along field boundaries and can be cut during harvesting. This mod aims to recreate that behavior in Farming Simulator 25.

## Features
- Grain and corn headers cut grass and meadow

### Planned features
- Combine straw effects when cutting grass only
- Grass being transported on the header and fed in to the combine
- The ability to cut weeds and short grass/meadow too (possibly being a setting)

## Installation

To install the latest version go to [releases](https://github.com/Mr-A-Voigt/FS25-Field-Edge-Harvesting/releases) find the newest version download the `FS25_Field_Edge_Harvesting.zip` under assets and then put the zip folder in `Documents/My Games/FarmingSimulator2025/mods/`

To try out the new in development features you need to download the leatest version as described above then un zip it go to [scriptsWorkInProgress](https://github.com/Mr-A-Voigt/FS25-Field-Edge-Harvesting/tree/main/scriptsWorkInProgress) download the script you want to try out put it in the folder you just un ziped then find the modDesc.xml locate <sourceFile filename=""/> then put in/change the link to the name of the lua script you downloaded then press save and put the folder in `Documents/My Games/FarmingSimulator2025/mods/`
