# Field Edge Harvesting

**A realism-focused mod for Farming Simulator 25**

Field Edge Harvesting is a Farming Simulator 25 mod that aims to make harvesting more realistic by allowing combine harvesters to collect grass growing along the edges of cultivated fields.

In real-world farming, grass and weeds can sometimes grow along field boundaries and may end up being collected during harvesting. This mod aims to recreate that behavior in Farming Simulator 25.
